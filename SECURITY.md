## AI Agent Security Boundary

AIエージェントがファイル、GitHub、Web、外部API、DeployなどのToolを扱う場合の情報分類、LLM Trust Boundary、最小権限、Prompt Injection、外部送信、人間承認は docs/ai-agent-security-boundary.md に定める。
これは脆弱性報告の受付手順を置き換えず、Security PolicyとAIエージェントの操作境界を別々に扱うための参照先である。
